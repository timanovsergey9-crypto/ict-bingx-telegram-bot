# Turtle Soup Plus One — BingX USDT-M signals

Telegram-бот сетапов **Turtle Soup Plus One** (Raschke & Connors, *Street Smarts*, гл. 5) по фьючерсам BingX USDT-M.

Старый сканер Sweep+MSS+FVG в Kill Zone молчал: на утреннем прогоне 12.11 он обошёл 787 пар и не дал ни одного `Сигнал:`. Чистый ICT на тех же данных не выдержал строгий бэктест. Рабочей оказалась **Plus One на 4ч**. Этот бот сканирует **только 4ч**; дневной таймфрейм перенесён в `bingx-signal-bot`, чтобы сигналы не дублировались.

## Правила (заморожены)

- Лонг: закрытый бар делает новый 20-барный минимум, прежний минимум не младше 3 баров, закрытие **на или ниже** этого уровня. На следующем баре — buy stop **на** прежнем минимуме. Иначе отмена.
- Стоп: 0.02% под минимумом Day-1 / Day-2. Цель 2R, выход по закрытию 8-го бара. Шорт — зеркало.
- Вселенная: открытые USDT-M, без NC*, 24ч объём ≥ $5M.
- Kill Zone **не** используется: фильтр сессий в исследовании не прошёл DEV-гейты и как раз оставлял бота без скана.

Холдаут 12.02.2026–11.11.2026, 31 монета, издержки 0.07%/сторона: **+0.181R**, PF 1.33, 25/31 монет, 4.24 сделки/день, сетап в **91.6%** календарных дней. Ребро скромное. Не финансовый совет.

## GitHub Actions

1. Secrets: `TELEGRAM_TOKEN`, `CHAT_ID`.
2. Расписание: `5 */4 * * *` (5 минут после закрытия 4ч свечи UTC).
3. Один короткий скан, не 4-часовой цикл. При сетапе — сообщение в Telegram; если сетапа нет — тишина (это нормально).

Локально:

```bash
pip install -r requirements.txt
python bot.py --selftest
python bot.py --dry-run          # живой рынок, без Telegram
python bot.py --replay 14        # бар-за-баром за 14 дней + исходы 2R/8 баров
```

`--scan-once` шлёт в Telegram, только если заданы `TELEGRAM_TOKEN` и `CHAT_ID`.
